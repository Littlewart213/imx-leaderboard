PANDUAN SINGKAT

Siap tampil di booth.

  1. Buka file ini di Chrome atau Edge pada laptop. Halaman pertama adalah admin untuk promotor.
  2. Input nama dan total belanja lebih dari Rp1.000.000. Klik Simpan. Untuk mengubah total peserta yang sama, klik Edit pada daftar.
  3. Klik Buka layar leaderboard. Tab baru hanya menampilkan nama dan peringkat. Biarkan tab admin tetap terbuka.
  4. Hubungkan TV/monitor dengan mode Extend. Pindahkan tab leaderboard ke layar booth, lalu tekan F atau F11 untuk layar penuh.
  5. Klik Backup data secara berkala. File JSON dapat dipulihkan lewat Pulihkan backup. Backup menyimpan nama serta nominal; simpan untuk kebutuhan admin.

Versi ini untuk satu laptop dan browser yang sama. Tab display mengikuti admin otomatis tanpa internet. HP/laptop lain belum tersambung. Gunakan satu tab admin agar input tidak saling menimpa.

Nama yang sama tidak dijumlahkan otomatis. Saat nama sudah terdaftar, aplikasi meminta konfirmasi untuk mengganti total. Untuk dua orang dengan nama yang sama, gunakan pembeda, misalnya “Budi A.” dan “Budi S.”

Peringkat pertama selalu terlihat. Jika daftar penuh, nama lainnya berganti halaman otomatis setiap 9 detik. Jika total sama, urutan mengikuti waktu pertama peserta dicatat.

Gunakan file, folder, dan browser yang sama selama event. Memindahkan file, mode Incognito, atau menghapus data browser dapat memutus akses ke data tersimpan. Pulihkan lewat backup jika diperlukan.
